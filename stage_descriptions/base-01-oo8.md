A [prompt](https://app.codecrafters.io/concepts/what-is-a-shell-prompt) tells the user that the shell is ready for a command. In this stage, you'll print that prompt.

### The prompt

The prompt is exactly `$ `: a dollar sign followed by one space, with no newline. User input will appear on that same line.

### Tests

The tester starts your program with `./your_program.sh` and checks for the prompt on standard output (stdout). Reading and running commands come later. Printing the prompt is enough for this stage.
